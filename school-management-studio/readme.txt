A modern, glassmorphic School Management System for WordPress with sidebar navigation and dark mode.

== Description ==

School Management Studio is a fresh take on managing your school in WordPress. The plugin features a sidebar-first admin layout, glassmorphism cards, soft pastel palette, full dark mode support, and inline SVG icons (no external font files). It's a sister plugin to Smart School Manager but with a brand-new visual identity.

= Key Modules =

* Studio (Dashboard, Schools, Sessions, Classes & Categories, Settings)
* Students (List, Wizard form, Admissions, Inquiries, ID Cards, Certificates, Promote, Birthdays)
* Staff (Directory, ID Cards, Attendance, Leaves, Roles)
* Academic (Subjects, Attendance, Timetables, Homework, Materials, Notices, Events, Meetings)
* Examinations (Exams, Groups, Results, Admit Cards)
* Accounting (Fees, Monthly Generator, Invoices, Print Center, Collect, History, Concessions, Income, Expenses, Reports)
* Library (Books, Issued, Cards)
* Hostel (Hostels, Rooms)
* Transport (Routes, Vehicles)
* Live Lectures, Support Tickets, Notifications, Logs, Print Center

= 100% Genuine =

* No bundled minified third-party libraries — every file is hand-written PHP/CSS/JS.
* Inline SVG icon set (no font files, no CDN, no false-positive AV triggers).
* Optional Chart.js loads from official jsDelivr CDN only on chart pages, and can be disabled in Settings.

== Installation ==

1. Upload the `school-management-studio` folder to `/wp-content/plugins/`, or upload the zip via Plugins → Add New → Upload.
2. Activate from the Plugins screen.
3. Click "Studio" in your admin sidebar to open the new dashboard.
